## AnalyticsScreen Overhaul

### Problem
The Analytics screen had a hardcoded pie chart showing nonexistent devices ("Router", "Cámara", "Ventilador") with `Math.random()` data. No energy consumption data was shown. The screen used raw telemetry with 5-second polling — overkill for historical analytics.

### Solution — Complete Rewrite (`src/screens/AnalyticsScreen/AnalyticsScreen.tsx`)

| Feature | Before | After |
|---------|--------|-------|
| **Pie chart** | Fake 3-slice pie with random data | Real per-device power distribution from all user devices |
| **Energy data** | None | kWh total, avg W, peak W from `getTelemetryAggregates()` |
| **Line chart** | Raw last-30-readings, 5s polling | Time-bucketed aggregates (hourly/daily) with fallback to raw |
| **Time range** | None | Segmented control: 24h / 7d / 30d |
| **Device selector** | Hardcoded MAC, no switching | Custom modal bottom-sheet picker when >1 device |
| **Loading** | Single spinner for everything | Separate `isLoading` (charts) + `isPieLoading` (pie chart) |
| **Animations** | Instant snaps | `LayoutAnimation.configureNext(Presets.easeInEaseOut)` on tab switches, data loads |
| **Android animations** | Didn't work | Added `UIManager.setLayoutAnimationEnabledExperimental(true)` |
| **Exports** | Raw telemetry only | Aggregate mode (kWh/W/Wh columns) + raw fallback mode |

### New Components

- **`formatBucketLabel(bucket, granularity)`** — "14:00" for hourly, "12/05" for daily
- **`truncateLabel(name, maxLen)`** — "VeryLongDeviceNa…" for pie donut text
- **`TIME_RANGE_LABELS`** — "Últimas 24 horas", "Últimos 7 días", "Últimos 30 días"
- **`renderDevicePickerModal()`** — Slide-up modal with device list, check-circle selection, online dot indicator, cancel button

### Data Flow

```
Mount → fetchDevices() (for picker + pie chart)
      → fetchDeviceAnalytics() → getTelemetryAggregates() + getTelemetryHistory()
      → fetchPieData() → getTelemetryHistory(mac, 1) for each device

Change time range → refetch aggregates (no polling)
Change device → refetch aggregates + update pie chart
Refresh button → refetch all
```

### Bug Fixes (Assessment Phase)

1. **Android LayoutAnimation** — Added `UIManager.setLayoutAnimationEnabledExperimental(true)` at module level. Without this, all `LayoutAnimation` calls are no-ops on Android.
2. **Bucket label formatting** — `a.bucket.slice(11, 16)` broke for daily buckets. Replaced with `formatBucketLabel()` that handles both "2026-05-12T14:00:00" → "14:00" and "2026-05-12" → "12/05".
3. **Pie chart text overflow** — Long MAC addresses (17 chars) rendered inside a 90px donut. Added `truncateLabel()` (max 12 chars) for donut text; legend shows full names.
4. **Single-device case** — When there's only 1 device, the picker was completely hidden. Now shows a read-only label card with the device name.
5. **Pie chart loading** — Showed "Sin datos de dispositivos" while fetching. Now shows a spinner with "Cargando dispositivos...".
6. **Energy card subtitle** — Was static "Periodo seleccionado". Now shows dynamic text like "Últimas 24 horas" based on selected time range.
7. **Modal touch propagation** — Changed from `<View onStartShouldSetResponder>` to `<Pressable onPress={e.stopPropagation()}>` for idiomatic React Native bottom-sheet behavior.
8. **Removed stale `selectedMacRef`** — Replaced with direct state check in the initial mount effect.
